# CIFAR-10 图像分类（PyTorch CNN）

用 PyTorch 从零搭建卷积神经网络，在 CIFAR-10 数据集上完成 10 类图像分类任务。

## 数据集

- CIFAR-10：6 万张 32×32 彩色图片
- 训练集 5 万张，测试集 1 万张
- 10 个类别：飞机、汽车、鸟、猫、鹿、狗、青蛙、马、船、卡车

## 数据预处理

- 转 Tensor
- 归一化：均值 0.5，标准差 0.5（三通道）

## 模型结构

自定义 CNN，3 层卷积 + 2 层全连接：

| 层 | 配置 |
|---|---|
| Conv1 | 3→32, 3×3, padding=1 + ReLU + MaxPool |
| Conv2 | 32→64, 3×3, padding=1 + ReLU + MaxPool |
| Conv3 | 64→128, 3×3, padding=1 + ReLU + MaxPool |
| FC1 | 128×4×4 → 256 + ReLU + Dropout(0.3) |
| FC2 | 256 → 10 |

## 训练配置

- 损失函数：CrossEntropyLoss
- 优化器：Adam，lr=0.001
- Batch size：64
- Epochs：10
- 设备：CPU

## 结果

| 指标 | 数值 |
|---|---|
| 训练准确率 | 88.62% |
| 测试准确率 | 76.33% |
| 训练 Loss（最终） | 0.3171 |
| 测试 Loss | 0.7972 |

训练与测试准确率相差约 12 个百分点，存在轻微过拟合，但在无数据增强、无预训练的条件下属于正常范围。

## 混淆矩阵分析

各类别测试准确率：

| 类别 | 准确率 |
|---|---|
| car | 88.9% |
| frog | 86.9% |
| ship | 84.6% |
| truck | 78.8% |
| plane | 78.6% |
| deer | 76.8% |
| horse | 74.7% |
| bird | 70.7% |
| dog | 65.6% |
| **cat** | **48.1%** |

主要混淆对：

- **猫 ↔ 狗**：猫被误判为狗 171 次，狗被误判为猫 131 次，是最严重的混淆
- **鹿 ↔ 马**：双向各 92 次
- **鸟 → 鹿 / 青蛙**：76 / 66 次
- **飞机 → 鸟**：62 次

32×32 的低分辨率下，外形相似的动物类别难以区分，这是 CIFAR-10 上的普遍现象。

## 环境

Python 3.6+，PyTorch 1.10，torchvision，matplotlib，seaborn，scikit-learn

## 可改进方向

- 数据增强（随机翻转、裁剪）缓解过拟合
- 使用 BatchNorm 加速收敛
- 迁移学习（ResNet18 预训练）可提升至 90%+
- 学习率调度（StepLR / CosineAnnealing）
